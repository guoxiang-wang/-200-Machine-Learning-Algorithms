# 异常值处理方法

_异常值不等于错误值。先确认它为什么出现，再决定是否处理。_

---

## 🔍 先识别

- [箱线图分析](20_异常值处理方法-箱线图分析.md)：适合快速查看单变量分布
- [IQR（四分位距）法](20_异常值处理方法-IQR（四分位距）法.md)：不依赖均值和标准差
- [标准差法](20_异常值处理方法-标准差法.md)：适合分布假设较明确的数据
- [Z-score 方法](20_异常值处理方法-Z-Score 标准化.md)：用标准差倍数表达偏离程度
- [聚类法](20_异常值处理方法-聚类法.md)：从多变量结构寻找稀疏区域

## 🔧 再处理

- [剪尾法](20_异常值处理方法-剪尾法.md)：限制极端值的影响
- [分箱法](20_异常值处理方法-分箱法处理.md)：降低精细数值带来的波动
- [中位数填充](20_异常值处理方法-中位数填充.md)：对偏态数据通常比均值稳定
- [均值填充](20_异常值处理方法-均值填充.md)：仅在分布和任务允许时使用

> ⚠️ **提醒：** 任何处理都应只根据训练集确定规则，并保留处理前后的分布对比。
