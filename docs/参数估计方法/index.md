# 参数估计方法

_从观测数据反推模型中的未知量。不同方法的区别，往往在于如何描述误差、如何使用先验。_

---

## 📍 建议阅读顺序

1. [最小化均方误差](19_参数估计方法-最小化均方误差.md)：先理解“选择一个目标函数”
2. [最小二乘估计](19_参数估计方法-最小二乘估计.md)：从几何和线性模型继续展开
3. [最大似然估计](19_参数估计方法-最大似然估计.md)：把概率模型带进来
4. [贝叶斯估计](19_参数估计方法-贝叶斯估计.md)：加入先验信息
5. [EM 算法](19_参数估计方法-EM算法.md)：处理含隐变量或缺失结构的问题

## 🔍 阅读时抓住的问题

- 参数是什么，数据又是什么
- 优化的目标函数从哪里来
- 解是闭式表达，还是需要迭代
- 估计结果依赖哪些分布假设
